# เว็บไซต์ CICM Dermatology: วิธีติดตั้ง

ผมจัดทำเว็บไซต์นี้ให้หลักสูตรตจวิทยา (หลักสูตรนานาชาติ) และพร้อมให้ทดลองบนเซิร์ฟเวอร์แล้วครับ เว็บไซต์เป็น HTML, CSS และ JavaScript ล้วน และไม่ต้องใช้ PHP ฐานข้อมูล หรือโปรแกรมอื่นบน nginx 1.30.6 กรุณาคัดลอกโฟลเดอร์ `dermatology` ไปไว้ใน web root แล้วเปิด https://cicm.tu.ac.th/dermatology/

## สิ่งที่อยู่ในไฟล์นี้

| รายการ | ใช้ทำอะไร |
| --- | --- |
| `dermatology/` | ตัวเว็บไซต์ ให้คัดลอกโฟลเดอร์นี้ขึ้นเซิร์ฟเวอร์ |
| `nginx-dermatology.conf` | การตั้งค่า nginx สำหรับที่อยู่ `/dermatology` และการแคช |
| `INSTALL-EN.md`, `INSTALL-TH.md` | วิธีติดตั้งฉบับภาษาอังกฤษและภาษาไทย |

## ทดลองบน localhost

1. คัดลอก `dermatology/` ไปไว้ใน web root ของ nginx บนเครื่อง เช่น `/var/www/html/dermatology/` บน Linux หรือ `C:\nginx\html\dermatology\` บน Windows
2. เปิด http://localhost/dermatology/ ในเบราว์เซอร์

กรุณาเปิดผ่าน nginx แทนการดับเบิลคลิก `index.html` เพราะหน้าเว็บโหลดเนื้อหาจาก `data/*.json` ซึ่งเบราว์เซอร์จะบล็อกเมื่อเปิดจากที่อยู่ `file://`

## ติดตั้งบน cicm.tu.ac.th

1. คัดลอก `dermatology/` ไปไว้ใน web root ของ cicm.tu.ac.th ให้หน้าแรกอยู่ที่ `<web root>/dermatology/index.html`
2. วางสองบล็อกจาก `nginx-dermatology.conf` ลงใน `server` ของ cicm.tu.ac.th แล้วแก้ `root` ให้ตรงกับ web root ของเซิร์ฟเวอร์
3. รัน `nginx -t` แล้วตามด้วย `nginx -s reload`
4. เปิด https://cicm.tu.ac.th/dermatology/ แล้วตรวจว่ารูปภาพ วิดีโอแนะนำหลักสูตร และตารางงานวิจัยโหลดขึ้นครบ

ลิงก์ทุกจุดในเว็บไซต์เป็นแบบ relative และใช้งานใต้ `/dermatology/` ได้

## ตัวเลือกรูปแบบให้อาจารย์เลือก

หน้าแรกมีหน้าเปิดสามแบบและรูปแบบการแสดงคณาจารย์สามแบบให้อาจารย์เลือก ปุ่ม "เลือกรูปแบบ" ที่มุมขวาล่างของหน้าแรกใช้สลับระหว่างตัวเลือก เมื่ออาจารย์เลือกแล้ว ผมจะลบตัวเลือกที่เหลือและปุ่มนี้ออก

## ก่อนเปิดใช้งานจริง

- ทุกหน้ามี `<meta name="robots" content="noindex, nofollow">` เพื่อไม่ให้ Google แสดงเว็บไซต์ในผลค้นหาตอนนี้ ผมจะเอาออกเมื่อ CICM อนุมัติเว็บไซต์
- เว็บไซต์ชุดเดียวกันนี้เปิดเป็นตัวอย่างอยู่ที่ https://shinigami1235-creator.github.io/cicm-dermatology/ ผมจะปิดชุดนั้นเมื่อเว็บไซต์เปิดใช้งานบน cicm.tu.ac.th แล้ว
- หน้าตจวิทยาเดิมที่ https://www.cicm.tu.ac.th/academicG-DM.php สามารถตั้ง redirect มาที่ https://cicm.tu.ac.th/dermatology/ ได้เมื่อเว็บไซต์เปิดใช้งาน

## เซิร์ฟเวอร์และระบบหลังบ้านสำหรับแก้ไขเนื้อหา

ตัวเว็บไซต์ไม่ต้องใช้ PHP หรือฐานข้อมูล เจ้าหน้าที่แก้ไขเนื้อหาผ่าน WordPress ด้วยปลั๊กอิน CICM Dermatology Content ในโฟลเดอร์ `wordpress-plugin` ของไฟล์นี้ WordPress ทำหน้าที่เก็บเนื้อหาและเขียนไฟล์ `data/content.json` ลงในโฟลเดอร์เว็บไซต์ทุกครั้งที่กดบันทึก ผู้เข้าชมจึงไม่ได้ผ่าน WordPress และเว็บไซต์ยังเปิดได้แม้ WordPress จะล่ม สิ่งที่ควรเตรียมมีดังนี้

| รายการ | เซิร์ฟเวอร์ตอนนี้ | สิ่งที่ต้องเตรียม |
| --- | --- | --- |
| nginx | 1.30.6 | พร้อมใช้ |
| PHP | 8.4.27 | พร้อมใช้ |
| MariaDB | 10.5.29 | กรุณาอัปเกรดเป็น 10.11 LTS หรือ 11.4 LTS ก่อนติดตั้งระบบหลังบ้าน เพราะ 10.5 หมดอายุการสนับสนุนเมื่อ 24 มิถุนายน 2568 และไม่ได้รับการแก้ไขด้านความปลอดภัยอีก WordPress ยังทำงานบน 10.5 ได้ แต่ปัจจุบันแนะนำเวอร์ชัน 10.6 ขึ้นไป |
| PHP extensions | mysqli, curl, mbstring | กรุณาเพิ่ม gd หรือ imagick, exif, fileinfo, intl, xml (dom) และ zip โดย WordPress ใช้ gd หรือ imagick ย่อขนาดรูปที่เจ้าหน้าที่อัปโหลด |
| Server charset | latin1 | สร้างฐานข้อมูลของเว็บไซต์เป็น `utf8mb4` กับ `utf8mb4_unicode_ci` เพราะข้อความภาษาไทยต้องใช้ |
| ผู้ใช้ฐานข้อมูล | root3 | สร้างผู้ใช้แยกที่เข้าถึงได้เฉพาะฐานข้อมูลของเว็บไซต์ |
| ขนาดไฟล์อัปโหลด | | ตั้ง `client_max_body_size` ใน nginx และ `upload_max_filesize` กับ `post_max_size` ใน PHP อย่างน้อย 64M สำหรับไฟล์ PDF และรูปภาพ |

## ติดตั้งระบบหลังบ้าน

1. ติดตั้ง WordPress ที่ `/dermatology/cms/` (หรือที่อยู่อื่นตามสะดวก) โดยใช้ฐานข้อมูล `utf8mb4` และผู้ใช้ฐานข้อมูลแยกของตัวเอง
2. คัดลอกโฟลเดอร์ `wordpress-plugin/cicm-dermatology-content` ไปไว้ที่ `wp-content/plugins/` แล้วกดเปิดใช้งานในเมนู Plugins
3. เพิ่มสองบรรทัดนี้ใน `wp-config.php` โดยใส่โฟลเดอร์และที่อยู่จริง
   ```php
   define( 'CICM_SITE_DIR', '/var/www/html/dermatology' );
   define( 'CICM_SITE_URL', 'https://cicm.tu.ac.th/dermatology/' );
   ```
4. ให้สิทธิ์ผู้ใช้ PHP เขียนไฟล์ได้เฉพาะโฟลเดอร์ `dermatology/data/` เพราะปลั๊กอินเขียน `content.json` ที่นั่นที่เดียว และจะไม่ยอมเขียนลงโฟลเดอร์ที่ไม่มี `index.html`, `js/site.js` และโฟลเดอร์ `data`
5. เปิดเมนู CICM Dermatology > Settings ในหน้าแดชบอร์ด แล้วกด Import from the site เพื่อคัดลอกเนื้อหาที่เว็บไซต์แสดงอยู่ตอนนี้เข้า WordPress
6. สร้างบัญชีระดับ Editor ให้เจ้าหน้าที่แต่ละคนที่แก้ไขเนื้อหา โดย Editor จะเห็นเมนู CICM Dermatology และมีเพียงผู้ดูแลระบบที่เห็นหน้า Settings

จากนั้นเจ้าหน้าที่แก้ไขประกาศ หลักสูตรและค่าเล่าเรียน อาจารย์ประจำและอาจารย์พิเศษ กลุ่มโรงพยาบาล เจ้าหน้าที่วิชาการ ผลงาน เอกสารดาวน์โหลด สถาบันฝึกอบรมต่างประเทศ โพสต์ Facebook และแผนการศึกษาได้ การบันทึกแต่ละครั้งแสดงผลบนเว็บไซต์ทันทีที่โหลดหน้าใหม่ และแท็บ History เก็บการบันทึก 15 ครั้งล่าสุดไว้ย้อนกลับได้ รูปภาพและแบบฟอร์ม PDF อัปโหลดผ่านคลังสื่อของ WordPress

หน้าของ WordPress นอกแดชบอร์ดจะพาผู้เข้าชมไปที่เว็บไซต์ และเนื้อหาทั้งหมดเปิดเป็น JSON ได้ที่ `/wp-json/cicm/v1/content`

เมื่อเปิดเว็บไซต์บน localhost ได้แล้วรบกวนแจ้งผมด้วยครับ หรือถ้ามีส่วนไหนไม่ทำงาน ส่งภาพหน้าจอมาได้เลยครับ
