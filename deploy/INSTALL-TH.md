# เว็บไซต์ CICM Dermatology: วิธีติดตั้ง

ผมจัดทำเว็บไซต์นี้ให้หลักสูตรตจวิทยา (หลักสูตรนานาชาติ) และพร้อมให้ทดลองบนเซิร์ฟเวอร์แล้วครับ เว็บไซต์เป็น HTML, CSS และ JavaScript ล้วน ไม่ใช้ PHP และไม่ใช้ฐานข้อมูล จึงไม่ต้องติดตั้งอะไรเพิ่มบน nginx 1.30.6 กรุณาคัดลอกโฟลเดอร์ `dermatology` ไปไว้ใน web root แล้วเปิด https://cicm.tu.ac.th/dermatology/

## สิ่งที่อยู่ในไฟล์นี้

| รายการ | ใช้ทำอะไร |
| --- | --- |
| `dermatology/` | ตัวเว็บไซต์ ให้คัดลอกโฟลเดอร์นี้ขึ้นเซิร์ฟเวอร์ |
| `nginx-dermatology.conf` | การตั้งค่า nginx สำหรับที่อยู่ `/dermatology` และการแคช |
| `INSTALL-EN.md`, `INSTALL-TH.md` | วิธีติดตั้งฉบับภาษาอังกฤษและภาษาไทย |

## ทดลองบน localhost

1. คัดลอก `dermatology/` ไปไว้ใน web root ของ nginx บนเครื่อง เช่น `/var/www/html/dermatology/` บน Linux หรือ `C:\nginx\html\dermatology\` บน Windows
2. เปิด http://localhost/dermatology/ ในเบราว์เซอร์

กรุณาเปิดผ่าน nginx แทนการดับเบิลคลิก `index.html` เพราะหน้าเว็บโหลดเนื้อหาจาก `data/*.json` ซึ่งเบราว์เซอร์จะบล็อกเมื่อเปิดจากที่อยู่ `file://`

## ติดตั้งบน cicm.tu.ac.th

1. คัดลอก `dermatology/` ไปไว้ใน web root ของ cicm.tu.ac.th ให้หน้าแรกอยู่ที่ `<web root>/dermatology/index.html`
2. วางสองบล็อกจาก `nginx-dermatology.conf` ลงใน `server` ของ cicm.tu.ac.th แล้วแก้ `root` ให้ตรงกับ web root ของเซิร์ฟเวอร์
3. รัน `nginx -t` แล้วตามด้วย `nginx -s reload`
4. เปิด https://cicm.tu.ac.th/dermatology/ แล้วตรวจว่ารูปภาพ วิดีโอแนะนำหลักสูตร และตารางงานวิจัยโหลดขึ้นครบ

ลิงก์ทุกจุดในเว็บไซต์เป็นแบบ relative จึงใช้งานใต้ `/dermatology/` ได้โดยไม่ต้องแก้โค้ด

## ดีไซน์สามแบบให้อาจารย์เลือก

เว็บไซต์มีดีไซน์สามแบบเพื่อให้อาจารย์เลือกหนึ่งแบบ

| ดีไซน์ | หน้าแรก |
| --- | --- |
| ชั้นผิว (Skin layers) | `index.html` |
| แผ่นภาพแอตลาส (Atlas plates) | `atlas.html` |
| สมุดหลักสูตร (Program book) | `book.html` |

ปุ่มสี่เหลี่ยมที่มุมขวาล่างของทุกหน้าใช้สลับระหว่างสามแบบ เมื่ออาจารย์เลือกแล้ว ผมจะลบอีกสองแบบและปุ่มนี้ออก

## ก่อนเปิดใช้งานจริง

- ทุกหน้ามี `<meta name="robots" content="noindex, nofollow">` เพื่อไม่ให้ Google แสดงเว็บไซต์ในผลค้นหาตอนนี้ ผมจะเอาออกเมื่อ CICM อนุมัติเว็บไซต์
- เว็บไซต์ชุดเดียวกันนี้เปิดเป็นตัวอย่างอยู่ที่ https://shinigami1235-creator.github.io/cicm-dermatology/ ผมจะปิดชุดนั้นเมื่อเว็บไซต์เปิดใช้งานบน cicm.tu.ac.th แล้ว
- หน้าตจวิทยาเดิมที่ https://www.cicm.tu.ac.th/academicG-DM.php สามารถตั้ง redirect มาที่ https://cicm.tu.ac.th/dermatology/ ได้เมื่อเว็บไซต์เปิดใช้งาน

## เซิร์ฟเวอร์และระบบหลังบ้านสำหรับแก้ไขเนื้อหา

ตอนนี้เว็บไซต์ยังไม่ต้องใช้ PHP หรือฐานข้อมูล ระบบให้เจ้าหน้าที่แก้ไขเนื้อหาจะทำเป็น WordPress ในขั้นต่อไป และมีเรื่องที่ควรเตรียมดังนี้

| รายการ | เซิร์ฟเวอร์ตอนนี้ | สิ่งที่ต้องเตรียม |
| --- | --- | --- |
| nginx | 1.30.6 | พร้อมใช้ |
| PHP | 8.4.27 | พร้อมใช้ |
| MariaDB | 10.5.29 | กรุณาอัปเกรดเป็น 10.11 LTS หรือ 11.4 LTS ก่อนติดตั้งระบบหลังบ้าน เพราะ 10.5 หมดอายุการสนับสนุนเมื่อ 24 มิถุนายน 2568 และไม่ได้รับการแก้ไขด้านความปลอดภัยอีก WordPress ยังทำงานบน 10.5 ได้ แต่ปัจจุบันแนะนำเวอร์ชัน 10.6 ขึ้นไป |
| PHP extensions | mysqli, curl, mbstring | กรุณาเพิ่ม gd หรือ imagick, exif, fileinfo, intl, xml (dom) และ zip โดย WordPress ใช้ gd หรือ imagick ย่อขนาดรูปที่เจ้าหน้าที่อัปโหลด |
| Server charset | latin1 | สร้างฐานข้อมูลของเว็บไซต์เป็น `utf8mb4` กับ `utf8mb4_unicode_ci` เพราะข้อความภาษาไทยต้องใช้ |
| ผู้ใช้ฐานข้อมูล | root3 | สร้างผู้ใช้แยกที่เข้าถึงได้เฉพาะฐานข้อมูลของเว็บไซต์ |
| ขนาดไฟล์อัปโหลด | | ตั้ง `client_max_body_size` ใน nginx และ `upload_max_filesize` กับ `post_max_size` ใน PHP อย่างน้อย 64M สำหรับไฟล์ PDF และรูปภาพ |

เมื่อเปิดเว็บไซต์บน localhost ได้แล้วรบกวนแจ้งผมด้วยครับ หรือถ้ามีส่วนไหนไม่ทำงาน ส่งภาพหน้าจอมาได้เลยครับ
